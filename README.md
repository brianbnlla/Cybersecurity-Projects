# Cybersecurity & Hands-On Lab Portfolio

Welcome to my cybersecurity project repository. This repository contains detailed technical write-ups, documentation, and analysis reports covering active reconnaissance, Active Directory administration, malware analysis, and vulnerability exploitation.

---

## 🛠 Tools & Technologies
* **Operating Systems:** Kali Linux, Windows Server 2022, Android (Simulated)
* **Reconnaissance & Analysis:** Nmap, Wireshark, PowerShell, Hash utilities
* **Exploitation & Testing:** Metasploit Framework, SMB exploitation tools
* **Identity & Access Management:** Active Directory Domain Services (AD DS), Group Policy Objects (GPOs)

---

## 📂 Project Directory & Overview

### 1. Footprinting, Reconnaissance, and Scanning
* **File:** `Footprinting, Reconnaissance, an...`
* **Overview:** Executed passive and active network reconnaissance using advanced search operators and Nmap port scanning. Identified exposed public infrastructure, mapped active network hosts, and analyzed open port vulnerabilities to assess overall attack surface exposure.

### 2. Implementing and Managing Active Directory
* **File:** `Implementing and Managing Act...`
* **Overview:** Deployed an Active Directory Domain Services (AD DS) environment using Windows Server virtual instances. Established a domain controller, structured custom Organizational Units (OUs), and configured Group Policy Objects (GPOs) to enforce security baselines and role-based access control.

### 3. Malware Analysis
* **File:** `Malware Analysis.pdf`
* **Overview:** Conducted static malware analysis utilizing forensic tools. Generated cryptographic file hashes, extracted embedded strings, and analyzed binary architecture characteristics on ransomware samples using PowerShell and specialized utilities to identify IOCs (Indicators of Compromise).

### 4. Metasploit Android OS Attack Simulation
* **File:** `Metasploit Android OS attack si...`
* **Overview:** Performed a mobile penetration testing simulation using Metasploit to generate a custom reverse shell payload. Delivered the payload via an Apache web server to evaluate mobile application security controls and post-exploitation access mechanisms.

### 5. Performing Vulnerability Exploitation & Remediation
* **File:** `Performing Vulnerability Exploitat...`
* **Overview:** Targeted weak SMB network configurations using Metasploit and credential auditing tools. Harvested credentials, analyzed service-level vulnerabilities, and executed remediation controls to patch the exploit vectors and harden target configurations.

---

## 🔒 Key Takeaways & Defense Focus
* **Least Privilege & Hardening:** Enforced strict access controls and policy enforcement across Windows and Linux environments.
* **Risk Mitigation:** Paired offensive testing methodologies with defensive remediation steps to prioritize system stability and security baselines.
